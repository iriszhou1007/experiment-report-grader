实验5：路由器配置实验

通过 Console 完成路由器初始配置，验证以太网连通性，再通过 Telnet 验证远程登录与权限切换。

1. 实验目标

  1. 使用 Console 口接入路由器，识别常用的 Cisco IOS 命令模式。
  2. 配置主机和路由器以太网接口，结合接口状态与 Ping 结果判断连通性。
  3. 配置本地账户和 VTY 线路，区分远程登录认证与进入特权 EXEC 模式的验证。

2. 实验环境与拓扑

使用 Cisco Packet Tracer 8.2.1。操作系统以 Windows 11 为例。选用 1 台 1841 路由器（Router0）、1 台 2950-24 交换机（Switch1）和 2 台 PC-PT（PC0、PC1）。

3. A部分：Console 接入与接口配置

任务1：搭建拓扑并接入 Console

任务要求

  1. 按图1与表1搭建设备与连线，通过 PC0 的 Terminal 接入 Router0。后续路由器初始配置通过该终端完成。
  2. 在同一会话中识别用户 EXEC、特权 EXEC、全局配置和接口配置模式。

测试要求

  1. 打开 PC0 的 Terminal，按图2核对串口参数，进入路由器命令行。
  2. 参照图3和 IOS 命令帮助，依次进入四种模式，记录实际提示符。进入接口配置模式时选择 Fa0/0。

图3中的 Configure 对应 configure terminal。原图左下方的返回命令应为 disable，用于从特权 EXEC 返回用户 EXEC。

作答证据：本人搭建的拓扑、PC0 的 Terminal 会话及各模式提示符。

思考问题（报告必答）

  1. 图1中，PC0 的配置线和 PC1 的以太网链路各有什么用途？结合实际接线，解释 PC0 无需设置 IPv4 地址的原因。
  2. 根据 PC0 的终端记录，列出四种模式的提示符。举例说明本次查看接口状态、修改设备配置和修改接口配置分别在哪种模式下完成。

任务2：配置 IPv4 接口并验证连通性

任务要求

  1. 按表2配置 PC1 和 Router0 的 IPv4 地址。通过 PC0 的 Console 会话为 Router0 的 Fa0/0 配置地址。
  2. 保持地址与连线不变，对比 Fa0/0 关闭和启用两种情况下的接口状态与 Ping 结果。

测试要求

  1. 配置地址后，确认 Fa0/0 处于管理性关闭状态；若未关闭，先关闭该接口。通过 Console 查询接口状态，在 PC1 执行 ping 192.168.1.1。
  2. 启用 Fa0/0，等待以太网链路稳定后，通过 Console 查看 Fa0/0 的 IPv4 地址、接口状态和线路协议状态，再执行相同的 Ping 测试。若首次 Ping 出现部分超时，可再次测试，并结合后续结果和接口状态说明。
  3. 确认 PC1 能收到 Router0 的回显应答，并保留接口启用状态供任务3使用。

作答证据：Fa0/0 的地址与启用前后的接口状态、PC1 两次 Ping 的结果。

思考问题（报告必答）

  1. 配置地址后，Fa0/0 关闭和启用时的接口状态、线路协议状态及 Ping 结果分别怎样？用两次测试说明为什么只配置地址还不足以确认通信正常。
  2. 用表2中的地址和掩码判断 PC1 与 Fa0/0 是否在同一子网。PC1 Ping 192.168.1.1 时，需要路由器把分组转发到另一个网络吗？说明理由。

4. B部分：Telnet 登录与权限验证

任务3：配置 VTY 并验证两级访问权限

任务要求

  1. 在 PC0 的 Console 会话中创建本地账户 admin，使该账户登录后进入用户 EXEC 模式。使用独立的口令控制进入特权 EXEC 模式。
  2. 配置 VTY 0–4，允许 Telnet 接入，使用本地账户认证，设置会话空闲超时为 5 分钟。
  3. 登录口令和特权口令分别使用原课件的仿真实验值 456 和 123。本任务在 Packet Tracer 内完成。

测试要求

  1. 完成任务2后，在 PC1 执行 telnet 192.168.1.1。先测试一次错误的登录口令，记录认证失败的结果；若会话被断开，重新发起 Telnet，再用正确用户名和口令登录，记录结果。
  2. 正确登录后，记录提示符，并尝试进入全局配置模式。回到登录后的 EXEC 提示符，使用 enable 进入特权 EXEC，记录是否需要再次输入口令，再尝试进入全局配置模式。
  3. 完成验证后退出远程会话。

作答证据：VTY 相关配置、错误与正确口令的测试结果、进入特权 EXEC 前后的提示符及命令回显。

思考问题（报告必答）

  1. 从本人配置中指出 VTY 线路允许的接入协议和登录认证方式。设置 5 分钟空闲超时限制的是哪一段时间？
  2. 输入错误口令和正确口令时分别出现什么结果？从输出中如何区分 Telnet 连接已建立与用户已通过认证？
  3. 比较执行 enable 前后进入全局配置模式的结果。结合提示符和命令回显，说明登录口令与特权口令分别控制什么。
  4. 如果 PC1 能 Ping 通 Router0，却无法通过 Telnet 登录，你会先查哪两项路由器配置？分别说明如何验证。
