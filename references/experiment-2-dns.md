评分依据统一编号：RPT-1环境；RPT-2十题及证据；RPT-3图号、图名、引用和帧号；RPT-4提交文件，以上来自指导书第6节。RPT-5为沿用实验一的**教师补充计分口径**：对应文字描述、问题图每张2分封顶6分、无其他扣分时的首行缩进3分，不冒充指导书原文。

本实验没有要求资料查阅、资料帮助或两道反思小结，**不因此扣分**。第2题已有故障处理和复测要求，不另设排障栏目扣分。前文的设备名称、姓名拼音形式、身份标签、拓扑美观、每一步操作和命令书写形式，不增加独立扣分点；只用于理解第1—10题及本人证据。

## 二、固定扣分

每项从满分起评。所有普通问题须明确确认，相关类别合并一次，不逐题、逐子问、逐字段累计；分项最低0分。

| 明确问题 | 扣分 | 计入位置 |
|---|---:|---|
| PT配置验证及第1—2题分析整体未提供 | 5 | 第1项，替代该项其他扣分 |
| 真实DNS抓包及第3—8题分析整体未提供 | 8 | 第2项，替代该项其他扣分 |
| nslookup查询复核及第9—10题分析整体未提供 | 8 | 第3项，替代该项其他扣分 |
| 某组整组没有必要文字回答/分析，包括只有图无解释 | 4 | 对应第1/2/3项，替代该组局部分析问题 |
| 某组有分析，但有题明确完全未答、核心判断与本人证据直接矛盾，或整组完全无可定位实验依据 | 2 | 对应第1/2/3项，全部一般问题合并一次 |
| 某组有文字分析，但整组完全没有相关实验图 | 3 | 对应第1/2/3项，须原页核验；部分缺图不适用 |
| 要求的实验环境记录明确缺项 | 2 | 第4项，全部缺项合并一次 |
| 已提交图缺顺序图号、图下图名、正文引用或必要对应描述 | 每图2，最高6 | 第4项，同图多种缺陷只算一张，须原页核验 |
| 全报告无其他扣分时，普通中文多行正文首行明确无缩进 | 3 | 第4项，全报告唯一扣分，须原页核验 |

环境检查操作系统、Packet Tracer版本、Wireshark版本、真实抓包接口及真实DNS解析器IP；正文或可读截图均可，不苛求小修订号或特定操作系统。

## 三、十道题的简短核对清单

| 题号 | 核心内容 |
|---|---|
| DNS-Q1 | 直接IP、主域名和别名的ping结果，以及两次域名查询响应返回的资源记录 |
| DNS-Q2 | 修改DNS服务器地址后的测试结果、发现的问题、处理与复测 |
| DNS-Q3 | DNS双方IP、传输层协议和端口 |
| DNS-Q4 | 查询/响应ID及区分、配对依据 |
| DNS-Q5 | 两域名返回记录、响应权威性和ping实际使用的地址 |
| DNS-Q6 | 别名判断及实际规范名称 |
| DNS-Q7 | 客户端查询方式和判断依据 |
| DNS-Q8 | 首次/重复ping的DNS变化、缓存判断和依据 |
| DNS-Q9 | A查询与CNAME查询结果的区别 |
| DNS-Q10 | 两域名的实际CNAME查询结果及其是否支持任务3判断 |

任务3/4的真实查询目标为`www.baidu.com`与`www.scu.edu.cn`，不要求在公网解析PT内部实验域名。接受全文其他位置的等价实质回答，一段可回答多题，一份证据可供多题引用。某题已有基本正确的核心回答，不因子要点不全、未抄全部记录或文字简短按“完全未答”扣分。任务和测试能从上下文明确定位即可，不机械要求写“测试N”。各组仍只合并扣2分一次。

仅用于统一判断、不新增要求的参考：

- 配对可结合ID、查询名/类型和通信双方；AA用于判断响应权威性，RD表示请求递归，RA表示服务器支持递归，不要求从客户端抓包证明解析器内部的完整查询链。参见[RFC 1035 §4.1.1](https://www.rfc-editor.org/rfc/rfc1035.html#section-4.1.1)。
- CNAME及实际规范名以本人记录为准；A查询也可能携带CNAME关系，不能以“不是CNAME类型查询”否定其中的别名证据。参见[RFC 1034 §3.6.2](https://www.rfc-editor.org/rfc/rfc1034.html#section-3.6.2)。
- **PT的CNAME响应显示差异不扣分。** 任务2第1题中，若响应头`ANCOUNT`与PDU详情面板可见的Answer条数不一致（如`ANCOUNT=2`，面板只显示一条目标域名的A记录、未显示CNAME），不得仅据此扣“记录缺失”“配置错误”“分析矛盾”或“截图不完整”，也不计为问题图。不要求学生补出面板未显示的记录或专门解释此差异；其他独立、明确的问题仍按原规则处理。此口径仅针对PT仿真，不扩展为真实网络抓包的通用豁免。
- 不固定公网IP、TTL、别名链、记录数量或ping连通结果；不强制重复ping一定有/没有DNS请求。学生记录真实现象、以可见缓存/命令/报文作合理解释即可；不要求不存在的重复查询截图，不用今日公网结果反驳历史实验结果。

## 四、证据、去重与编排边界

1. **分别核对，再去重。** 三组题、环境和图编排分别检查，一项已扣不能跳过其他项。在现有分项说明`i`简述核对结果及页码，合格项可合并简写；同一事实已归其他规则而不另扣，简述归属，不新增字段或长表。
2. **同一事实只扣一次。** 全组缺图不能再用同一事实扣“无证据联系”；整组无分析扣4分后，不再就同一缺文字扣局部问题或图的描述。某判断缺陷已在任务3扣过，不因第10题引用该判断再扣同一事实；独立的第9/10题完全未答仍须核对。
3. **图与帧号分开。** 图号/图名/正文引用/描述归第4项。真实抓包帧号在正文、图中可读列表或明确标注中能定位即接受；某组全部缺少报文/帧号依据，合并该组一般问题2分，不逐帧扣分。单纯图号引用缺失不能再换成“帧号缺失”重复扣。
4. **按不同问题图计数。** 原页确认后，一个`screenshot_documentation_issue`记录最早三张问题图；每图2分封顶6分，同图多缺陷或多题引用不重复计。图名须在图下能清楚对应，不苛求标题措辞或像素距离；图1、图1-1等逻辑清楚的顺序编号可接受。
5. **图的记录格式沿用现有程序。** `figures`中写`p.N#imageK`、缺失要素和理由；要素为`FIG-numbering`、`FIG-caption`、`FIG-reference`、`FIG-description`。N为原PDF页码，K为该页实际实验图从上到下、同高从左到右的序号，不计页眉图标。顶层`requirements`取并集，相关页须确实查看并列入证据和视觉证据；不能以OCR缺字证明无图号或图名。
6. **缩进最后检查。** 仅全报告其他扣分清单为空时，检查普通中文多行叙述正文。首行明确与后续行左缘对齐、无首行缩进才扣3分；标题、题干、列表、代码、表格、图注和截图内部文字不算，单行/不清楚不扣，不苛求精确两个汉字。有其他扣分时不启用；没有缺陷仍允许100分。
7. **未看到不等于没写。** 先排除其他位置、等价表达、截断和OCR问题。图像/整体任务缺失须看原页；证据不清只标复核，不推断没做。仿真与真实环境须区分，但疑点不作为造假结论。

## 五、附件与发布

RPT-4的报告命名、`.pkt`正确恢复状态及`.pcapng`提交情况单列教师核验；**本版PDF报告100分不自动扣附件或命名分**。只收到PDF、目录没有附件或agent不能解析工程，都不是学生未提交的证明，不伪造PDF页码支持附件缺失。需完整提交清单及必要工具才能核验；未核验如实标记，不能称“全提交要求已通过”。如课程需要附件计分，应先明确单独规则和证据格式，再统一实施。

所有扣分`certainty=confirmed`，`fact=rule`，有要求编号则记录涉及的`requirements`。两遍独立盲评比较总分、事实、要求及实际计分图；总分差超过2分或事实不一致，生成待裁决草稿，未经教师明确裁决不得批准/写回，不平均两遍分数。

允许100分，不设置98分上限或无依据的最低扣分。超过80%处于92—98仅作观察，不据此虚构/撤销扣分；发布均分不低于90沿用透明的最小统一偏移，保留原始分。本版已正式发布，但尚无真实实验二报告复评数据，不承诺已达到稳定性或分布目标；采用时须重新`prepare`指定本JSON，不自动继承实验一细则，也不改写旧成绩。

本细则、机器规则JSON和原始指导书已随 Skill 一起发布。确认实验主题为实验二后，使用 assets/rubrics/experiment-2-dns.json 作为评分标准，并按 Skill 的固定流程完成稳定版本核验、前置检查、教师选择报告检查模式、首次评分、独立盲复评和教师审核。评分草稿不自动写回PDF。

RPT-4中的 .pkt 工程及 .pcapng 抓包附件核验与PDF报告评分分开处理。仅收到PDF、未提供附件目录或无法读取工程文件，都不能据此认定学生未提交附件，也不能从PDF分数中扣分；需要完整提交清单和相应检查工具时，教师可另行要求附件核验。PDF评分只按本细则列出的报告证据评分。
